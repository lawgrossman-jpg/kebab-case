# אתר עו"ד ישראל גרוסמן

אתר תדמית סטטי (HTML/CSS/JS ללא תלות בבנייה - build-free) עבור משרד עורכי הדין
של ישראל גרוסמן, בהתבסס על מסמך האפיון: מיצוב בתחומי רשלנות רפואית, נזיקין
וביטוח, ושפת מיתוג הנשענת על צבעי הלוגו (כחול נייבי + כסף מתכתי).

## מבנה הפרויקט

```
index.html            דף הבית — hero, תקציר אודות, תחומי עיסוק, וידג'ט וידאו, טופס יצירת קשר מהיר
about.html            אודות המשרד — מסלול מקצועי, קשרים רפואיים, האני-מאמין
practice-areas.html   4 דפי שירות מורחבים: רשלנות רפואית / תאונות דרכים ונזקי גוף / ביטוח / אזרחי-מסחרי
blog.html             "תבעתי ונושעתי" — מרכז ידע עם סינון קטגוריות (רפואי / ביטוח / סיפורים / "טעם של עו"ד")
contact.html          טופס יצירת קשר מלא, מפת הגעה, פרטי התקשרות
css/style.css         מערכת עיצוב אחת (צבעים, טיפוגרפיה, רכיבים) לכל האתר
js/main.js            תפריט מובייל, מודל וידאו, סינון בלוג, ולידציה בסיסית לטפסים
js/footer.js          פוטר משותף המוזרק בכל הדפים כדי לא לשכפל HTML
assets/logo.svg        לוגו (מונוגרם IG) בצבעי המיתוג
assets/favicon.svg     פאביקון
```

## הרצה מקומית

האתר סטטי לחלוטין - אין תהליך build. ניתן לפתוח את `index.html` ישירות
בדפדפן, או להריץ שרת מקומי פשוט:

```bash
python3 -m http.server 8000
```

## מה עדיין דורש השלמה לפני עלייה לאוויר

מסמך האפיון המקורי מבקש גם **מערכת ניהול תוכן (CMS)** לניהול מאמרים, מדיה
ולוח פניות (Leads) — אלה דורשים backend ואינם חלק מהקבצים הסטטיים כאן:

1. **טופס יצירת הקשר** - כרגע מבצע ולידציה בצד לקוח בלבד ומציג הודעת אישור,
   ללא שליחה בפועל. יש לחבר את ה-`fetch`/שליחת הטופס ב-`js/main.js` לשירות
   אמיתי (לדוגמה שרת עצמאי, Formspree/EmailJS, או אינטגרציה מול ה-CMS שייבחר),
   כדי שהפניות אכן יגיעו לדוא"ל המשרד וללוח בקרה מרוכז.
2. **ניהול מאמרים ווידאו** - מאמרי "טעם של עו"ד" ו"תבעתי ונושעתי" וכן קטעי
   הווידאו של "סליחה, יש לך חצי דקה?" מוצגים כרגע כתוכן לדוגמה קבוע בקוד.
   כדי לאפשר למשרד להעלות תוכן חדש בעצמו (כפי שמבוקש במסמך), יש להקים CMS
   בפועל (לדוגמה WordPress headless, או כל מערכת ניהול תוכן אחרת) ולחבר את
   הדפים לשליפת התוכן ממנו.
3. **וידאו אמיתי** - כרטיסי הווידאו בעמוד הבית הם placeholder; יש להטמיע
   נגן אמיתי (YouTube/Vimeo מוטמע) בכל כרטיס עם קישור לסרטון בפועל.
4. **תוכן לדוגמה** - הביוגרפיה, המאמרים וסיפורי ההצלחה כתובים כתוכן לדוגמה
   התואם למבנה שהתבקש; יש להחליפם בתוכן הסופי (ותוך שמירה על חיסיון עו"ד-לקוח
   בפרסום סיפורי לקוחות).

## נגישות ותאימות למגזר החרדי

העיצוב נשמר צנוע ומכובד (ללא תמונות אנשים, ללא אלמנטים שיווקיים אגרסיביים),
עם ניגודיות גבוהה לקריאות טקסטים משפטיים ורפואיים, כמבוקש במסמך האפיון.
